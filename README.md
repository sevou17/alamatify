# Alamatify

Alamatify adalah aplikasi web sederhana untuk membuat variasi teks alamat secara acak. Aplikasi ini menggunakan beberapa metode modifikasi teks, seperti penggandaan huruf, substitusi angka, perubahan kapitalisasi, dan variasi tanda baca.

Antarmuka dirancang dengan gaya minimalis yang terinspirasi dari Shopee Indonesia, menggunakan warna oranye `#EE4D2D` dan tipografi Roboto.

## Fitur

* **Input Alamat** — Memasukkan alamat melalui kolom teks.
* **Pengaturan Intensitas** — Mengatur tingkat penggandaan vokal, konsonan, dan substitusi angka.
* **Kapitalisasi** — Mengubah seluruh teks menjadi huruf kapital melalui opsi yang tersedia.
* **Variasi Tanda Baca** — Mengubah tanda koma menjadi titik atau spasi.
* **Tiga Variasi Hasil** — Menghasilkan tiga variasi alamat dalam satu proses.
* **Indikator Keterbacaan** — Menampilkan indikator keterbacaan untuk setiap hasil.
* **Salin ke Clipboard** — Menyalin hasil yang dipilih dengan satu klik.

## Cara Menggunakan

1. Masukkan alamat yang ingin divariasikan.
2. Sesuaikan intensitas modifikasi menggunakan slider.
3. Klik **Acak Alamat Sekarang** untuk menghasilkan tiga variasi.
4. Klik **Salin** untuk menyalin hasil yang diinginkan.

## Catatan

Perubahan karakter dapat memengaruhi keterbacaan dan keakuratan alamat. Pastikan alamat akhir tetap benar dan dapat dikenali oleh kurir maupun sistem validasi alamat.
